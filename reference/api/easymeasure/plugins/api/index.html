    easymeasure.plugins.api¶

    What a plugin is made of: Plugin, Channel, Action.

    A plugin is an add-on to the measurement engine that brings its own panels and processing. It runs on its own thread, next to the backend; whatever it does wrong (an exception, a crash, a loop that never ends) stays with the plugin. It talks to the backend through the same commands a front end uses (Plugin.backend), and it never talks to hardware: instruments are reached through their drivers, with the backend's limits and locks.

    A plugin can

    • add panels beside Instruments, Sweep editor and Queue, and tabs beside Live data (Plugin.ui, see easymeasure.plugins.ui),
    • provide channels and actions of its own (Plugin.provide): they appear as an instrument named after the plugin, to monitor, set by hand, alias and sweep like any other,
    • do work at intervals (Plugin.every, Plugin.after) and react to backend events (EVENTS, Plugin.on_backend_event).

    Everything a plugin's code runs - start, stop, timers, widget callbacks, backend events, the reads and writes of its channels - runs on the plugin's thread, one thing at a time, so a plugin needs no locks of its own.

    start ¶

    start() -> None

    Build the panels (self.ui.add_panel), provide channels, start timers.

    stop ¶

    stop() -> None

    Clean up. (Panels, channels and timers are removed by the framework, also when this is never reached because the plugin is stuck.)

    on_event ¶

    on_event(widget: str, event: str, value: Any) -> None

    A widget without its own callback was operated (click, turn with the steps, change with the new value).

    on_backend_event ¶

    on_backend_event(kind: str, data: Any) -> None

    A backend event of a kind in EVENTS.

    every ¶

    every(seconds: float, fn: Callable[[], Any]) -> Timer

    Run fn every seconds (on the plugin's thread; the next run is planned when this one has finished, so a slow fn never piles up).

    after ¶

    after(seconds: float, fn: Callable[[], Any]) -> Timer

    Run fn once, seconds from now.

    provide ¶

    provide(channels: Sequence[Channel] = (), actions: Sequence[Action] = ()) -> None

    Provide channels and actions, as an instrument named like the plugin (<name>.<channel>). Called again, the new lists replace the old.

    api_problem ¶

    api_problem(required) -> str

    Why a plugin written for API required cannot run here ("" if it can): the major versions must be equal, and its minor version no newer than this one.
