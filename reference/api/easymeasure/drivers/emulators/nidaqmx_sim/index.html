    easymeasure.drivers.emulators.nidaqmx_sim¶

    A stand-in for the nidaqmx package emulating one NI USB DAQ per device name.

    Only the part of the nidaqmx API the ni6211 / ni63xx drivers use is provided, with the same names, argument conventions and return shapes as nidaqmx 1.x (task.read() gives a float for one channel, a list per channel for several, lists of samples for timed reads). Each card is a USB-6211 unless define makes it another model of .._nidaq_models (channel counts, ranges, rates, digital port layout). The card is wired as a loop-back test box: aiK sees aoK (for every output), the other inputs carry 0.1 V × index plus a little noise, every counter counts a 1 kHz clock; USB-6211: port0 (digital inputs) reads port1 (outputs); X Series: every digital line is wired to the line half a port away (P0.0 ↔ P0.4 on an 8-line port), an input reads what its partner drives, otherwise 0 (pull-down).

    Errors follow DAQmx: invalid channels, ranges, rates or a resource that is already reserved (a digital line used by two tasks, an X Series counter's source PFI used as a digital line) raise errors.DaqError with DAQmx's codes.
