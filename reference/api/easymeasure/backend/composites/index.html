    easymeasure.backend.composites¶

    Composite (virtual) channels: definitions and their checks.

    Three kinds, all built from user formulas (easymeasure.common.exprs, so piecewise functions work: piecewise(x < 0, -x, x), a if c else b, where, interp tables):

    multi – multivariate write Variables x, y, … (each with its own name, min, max, unit and ramp rate) are channels of their own, named after the composite: the variables eps and U of gates are the channels gates.eps and gates.U (in the Manual panel, sweeps, scripts and other formulas). Its own formulas use the short names. Every target (an alias, a mapping, or a variable of another multivariate composite) is a formula of the variables::

        {"type": "multi", "name": "gates",
     "variables": [{"name": "eps", "min": -1, "max": 1, "unit": "V", "ramp_rate": 0.1},
                   {"name": "U", "min": 0, "max": 2}],
     "targets": {"VL": "U/2 + eps", "VR": "U/2 - eps"}}

Setting a variable writes the targets that depend on it (with the last set
value of the others).  Reading a variable gives the value it was last set to,
NaN before that.

``out_of_range`` says what happens when a combination of the variables would
drive a target outside its own range (an alias' limits …):

* ``"skip"`` (default): a sweep skips that point (as ``skip_point()`` before
  the swept channels are set); a direct write is refused;
* ``"error"``: refused everywhere; a sweep containing such a point fails
  validation;
* ``"clamp"``: the target is set to the nearest end of its range.

    read – composite read A formula of other channels (aliases, mappings, variables, other reads)::

        {"type": "read", "name": "R", "expression": "V / I if I != 0 else nan", "unit": "Ω"}

    map – simple mapping A one-to-one software channel for one hardware channel (alias, mapping or variable): forward gives the target value y from x, backward gives x from y; min/max (required) is the range of x. That backward(forward(x)) == x everywhere in the range is checked when the mapping is defined::

        {"type": "map", "name": "T", "target": "Vheater", "forward": "sqrt(x/10)",
     "backward": "10*y**2", "min": 0, "max": 50, "unit": "mW"}

    The dependency graph (writes and reads) is checked for cycles by the ~easymeasure.backend.channels.ChannelManager whenever a composite is added or replaced.
