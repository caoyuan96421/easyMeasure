    easymeasure.tray¶

    System-tray indicator for a running backend.

    Started automatically by python -m easymeasure.backend (disable with --no-tray). It runs as a separate process and talks to the backend like any other client, so the tray can never affect the backend; it exits on its own when the backend goes away.

    The icon colour shows the state (green idle, blue running, orange paused, red error/aborting, gray not reachable); the tooltip shows the current run and its progress. Menu: open the GUI, open the web page (starting remote access if it is off), pause / resume / abort, open the data folder or the log, shut the backend down. A notification pops up when a run ends.
