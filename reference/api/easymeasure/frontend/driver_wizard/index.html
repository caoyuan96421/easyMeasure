    easymeasure.frontend.driver_wizard¶

    Driver Wizard: build a driver for a command-based instrument without writing code.

    Pages: template → identity & connection → channels → actions → initialization → check, try on the instrument, save. The result is a driver file in the backend's <home>/drivers (see easymeasure/drivers/_command.py); saving loads it at once, and the wizard can reopen it later.

    TERMINATIONS module-attribute ¶

    TERMINATIONS = [('\\n  (LF)', '\n'), ('\\r\\n  (CR LF)', '\r\n'), ('\\r  (CR)', '\r'), ('none', '')]

    CH_COLS module-attribute ¶

    CH_COLS = ['Name', 'Kind', 'Access', 'Type', 'Unit', 'Get (query)', 'Set ({value})', 'Allowed values', 'Map (value=word)', 'Scale', 'Description']

    CH_KEYS module-attribute ¶

    CH_KEYS = ['name', 'config', 'access', 'dtype', 'unit', 'get', 'set', 'allowed', 'map', 'scale', 'description']

    CH_HELP module-attribute ¶

    CH_HELP = "<b>Data</b> channels are measured or swept (alias them in the setup); <b>config</b> channels are settings (range, mode, output …). <b>Get</b>: the query whose reply is the value (numbers: the first number in the reply). <b>Set</b>: the command, <code>{value}</code> marks where the value goes (<code>{value:.3f}</code> for a fixed format). <b>Allowed values</b>: <code>a | b | c</code> — a drop-down in the GUI. <b>Map</b>: <code>Voltage=VOLT | Current=CURR</code> translates values into the instrument's words (replies in SCPI short/long form and 1/0 for ON/OFF are recognised). <b>Scale</b>: reading × scale (instrument in mA, channel in A: 0.001). <b>vector</b>: a reply of comma-separated numbers."
