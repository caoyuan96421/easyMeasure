    InstrumentDialog ¶

    InstrumentDialog(drivers: dict, inst: Optional[dict] = None, parent=None, preset: Optional[dict] = None, conn=None)

    Bases: QDialog

    Add / edit an instrument. The address is an editable list of the ports found on the backend computer that the chosen driver accepts (its interfaces), devices whose identification matches the driver first (✓), plus the driver's suggestions (built-in emulator, NONE). Refresh scans again; *ask IDN? identifies GPIB / USB / LAN instruments that are not in use.
