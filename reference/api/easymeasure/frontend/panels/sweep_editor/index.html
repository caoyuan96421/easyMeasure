    easymeasure.frontend.panels.sweep_editor¶

    Sweep editor: create / modify / save / load arbitrary-dimensional sweeps.

    SPECIAL_RECORD module-attribute ¶

    SPECIAL_RECORD = ['@time', '@elapsed']

    HOOKS module-attribute ¶

    HOOKS = [('pre_sweep', 'Pre-sweep action', 'before the swept channels are set'), ('post_sweep', 'Post-sweep action', 'after the swept channels are set'), ('pre_record', 'Pre-record action', 'right before recording (e.g. trigger a meter)'), ('post_record', 'Post-record action', "right after recording (also sees 'values')")]

    HOOK_HELP module-attribute ¶

    HOOK_HELP = "# Python, runs at every point of this dimension.  Names: k (dimension), i (index),\n# index (this and outer indices), setpoints {channel: value}%s; get, set, action,\n# sleep, log, state ... (as in scripts).  e.g.  set('dmm.trigger')\n# skip_point() / skip_line() / end_sweep(): like continue / break / exit"

    FLOW_ACTIONS module-attribute ¶

    FLOW_ACTIONS = [('Skip this point', "skip_point()   # like 'continue': rest of this point skipped, its data NaN", 'skip_point(): end this point now (its data stay NaN); go on with the next point of this dimension'), ('Skip this line', "skip_line()   # like 'break': rest of this dimension's line skipped (NaN)", 'skip_line(): skip this point and the remaining points of this dimension (data NaN); the outer dimension continues'), ('Terminate the entire sweep', "end_sweep()   # like 'exit': stop the sweep here", "end_sweep(): stop the whole sweep (status 'terminated'); the post-sweep phase still runs")]

    DimensionEditor ¶

    DimensionEditor(parent=None)

    Bases: QWidget

    One dimension, laid out in the order every point runs:

    [pre-sweep action] → set swept channels → [post-sweep action] → pre-sample delay → [pre-record action] → record → [post-record action] → post-sample delay

    The four actions (per-point hooks) are hidden and off until ticked.
