    Backend commands¶

    Everything the front ends do goes through these commands, so a script can do the same. Call them with keyword arguments:

    from easymeasure.client import BackendClient
c = BackendClient.connect()
c.call("write_channel", name="Vg", value=0.2)

    or in-process on a Backend object (be.write_channel(name="Vg", value=0.2)). Role is the minimum role a remote user needs (local only: refused through the internet gateway). Commands marked ⚡ are served by a separate thread pool, so they answer even while every instrument is busy.

    group commands
    Connection and state ping, get_state, get_settings, set_settings, shutdown, start_tray, recent_logs
    Drivers and ports list_drivers, rescan_drivers, discover_resources, list_resources

    Connection and state¶

    ping¶

    ping() -> 'dict'

    Role: viewer ⚡

    Liveness check: {pong: <server time>, uptime: <s>}.

    get_state¶

    get_state() -> 'dict'

    Role: viewer ⚡

    Everything a front end shows, in one dict: uptime, settings, instruments, channels (see list_channels), monitor, actions (user actions), queue, current_run, resources and ramps (ramps of direct writes now running, see ramp_state).

    get_settings¶

    get_settings() -> 'dict'

    Role: viewer ⚡

    The backend settings (see DEFAULT_SETTINGS) plus derived values such as the effective data folder.

    set_settings¶

    set_settings(**kwargs) -> 'dict'

    Role: admin ⚡

    Change backend settings, e.g. set_settings(data_dir="D:/data", ppt_path="runs.pptx"). Unknown keys are refused; a data folder that cannot be created is refused. Returns the new settings.

    shutdown¶

    shutdown(force: 'bool' = False) -> 'str'

    Role: admin ⚡

    Shut the backend down (refused while a sweep runs, unless force).

    start_tray¶

    start_tray() -> 'dict'

    Role: local only

    Start the system-tray helper process (no-op if it is already running).

    recent_logs¶

    recent_logs(n: 'int' = 500, min_level: 'int' = 0) -> 'list'

    Role: viewer ⚡

    The last n log records at or above min_level (logging levels).

    Drivers and ports¶

    list_drivers¶

    list_drivers() -> 'dict'

    Role: viewer ⚡

    All drivers that could be loaded: {drivers: {name: {description, options, channels, shared, interfaces, idn_match, suggest}}, errors: {file: message}}.

    rescan_drivers¶

    rescan_drivers() -> 'dict'

    Role: admin

    Load the driver directories again (after adding or changing a driver file); returns the same as list_drivers.

    discover_resources¶

    discover_resources(interfaces: 'Optional[list]' = None, identify: 'bool' = False) -> 'dict'

    Role: admin

    Ports / devices of this computer by interface (see ResourceManager.discover); in-use entries name the instruments and carry their identification.

    list_resources¶

    list_resources() -> 'list'

    Role: viewer ⚡

    The ports in use: one entry per resource (address, interface, owners, shared flag).

    Driver Wizard¶

    wizard_templates¶

    wizard_templates() -> 'list'

    Role: admin

    The Driver Wizard's starting points (generic SCPI, SMU, DMM, line protocol).

    wizard_check¶

    wizard_check(definition: 'dict') -> 'dict'

    Role: admin

    Problems of a definition, and the Python file it would become.

    wizard_list¶

    wizard_list() -> 'list'

    Role: admin

    Drivers made with the wizard (they can be reopened).

    wizard_load¶

    wizard_load(name: 'str') -> 'dict'

    Role: admin

    The definition of a driver made with the wizard, to edit it again.

    wizard_save¶

    wizard_save(definition: 'dict', overwrite: 'bool' = False) -> 'dict'

    Role: admin

    Write the driver file, load it, and reconnect instruments that use it.

    wizard_try¶

    wizard_try(definition: 'dict', address: 'str', options: 'Optional[dict]' = None) -> 'dict'

    Role: admin

    Connect a temporary instrument with this definition and read every readable channel once (nothing is saved, nothing written). Errors are reported per channel, not raised.

    wizard_delete¶

    wizard_delete(name: 'str') -> 'None'

    Role: admin

    Delete a driver file made with the wizard (refused while an instrument uses it).

    Instruments¶

    add_instrument¶

    add_instrument(name: 'str', driver: 'str', address: 'str' = 'NONE', options: 'Optional[dict]' = None, connect: 'bool' = True) -> 'dict'

    Role: admin

    Add an instrument: a name of your choice, a driver from list_drivers, an address (GPIB0::12::INSTR, COM3, TCPIP0::…, DAQ::Dev1, SIM::…, NONE) and driver options. With connect it is connected at once; a failed connection is reported in the returned description (state, last_error) and retried on demand.

    update_instrument¶

    update_instrument(name: 'str', address: 'Optional[str]' = None, options: 'Optional[dict]' = None, driver: 'Optional[str]' = None) -> 'dict'

    Role: admin

    Change address/options/driver of an instrument (it is reconnected).

    remove_instrument¶

    remove_instrument(name: 'str') -> 'None'

    Role: admin

    Disconnect and remove an instrument (refused while aliases use it).

    connect_instrument¶

    connect_instrument(name: 'str') -> 'dict'

    Role: operator

    Connect an instrument that is disconnected; returns its description.

    disconnect_instrument¶

    disconnect_instrument(name: 'str') -> 'dict'

    Role: operator

    Disconnect an instrument (it stays in the setup); returns its description.

    reconnect_instrument¶

    reconnect_instrument(name: 'str') -> 'dict'

    Role: operator

    Disconnect and connect again (e.g. after a power cycle); returns its description.

    list_instruments¶

    list_instruments() -> 'list'

    Role: viewer ⚡

    Every instrument with its driver, address, options, state, last error, channels and actions.

    raw_query¶

    raw_query(instrument: 'str', command: 'str') -> 'str'

    Role: admin

    Send a command to an instrument and return its reply (admin only remotely).

    raw_write¶

    raw_write(instrument: 'str', command: 'str') -> 'None'

    Role: admin

    Send a command to an instrument without reading a reply (admin only remotely).

    Channels¶

    read_channel¶

    read_channel(name: 'str') -> 'Any'

    Role: viewer

    Read any readable channel: instrument.channel, an alias, a composite channel (gates.eps), a parameter or @time.

    write_channel¶

    write_channel(name: 'str', value: 'Any' = None, ramp: 'bool' = True) -> 'Any'

    Role: operator

    Write any writable channel. An alias keeps its limits and, with ramp, its ramp rate (composite channels: everything they drive); a channel of an instrument (src.V1, lockin.sensitivity) is written as it is; a value parameter takes the value (nothing moves); an action - of an instrument (dmm.reset) or a user action (zero_gates) - runs, value is not needed. Returns the value set (a user action: {status, error, elapsed}).

    set_many¶

    set_many(values: 'dict', ramp: 'bool' = True) -> 'dict'

    Role: operator

    Write several channels together (e.g. all variables of a composite; see write_channel). Everything is checked before anything is written.

    stop_ramps¶

    stop_ramps() -> 'list'

    Role: operator ⚡

    Stop the ramps of direct writes (write_channel, set_many: the Manual panel, clients) that are running now. Every channel stays where its ramp had got to; the write returns that value. Sweeps, scripts and user actions are not affected (use abort). Returns the channels that were ramping.

    ramp_state¶

    ramp_state() -> 'dict'

    Role: viewer ⚡

    {"active": [...]}: the ramps of direct writes now running (channels that move, the values asked for, since when). The event ramps sends the same whenever it changes.

    channel_info¶

    channel_info(name: 'str') -> 'dict'

    Role: viewer ⚡

    What a channel is: kind (hardware, config, action, alias, variable, map, read, parameter, user_action, special), access (r, w, rw), dtype, shape, unit, limits, ramp rate, allowed values.

    list_channels¶

    list_channels() -> 'dict'

    Role: viewer ⚡

    channels: every channel (channel_info plus its last value), as one list; aliases, composites, parameters: their definitions.

    Aliases and composites¶

    define_alias¶

    define_alias(replace: 'bool' = False, **alias) -> 'dict'

    Role: admin

    Define an alias: name, target (instrument.channel) and optional min, max, ramp_rate (units/s), ramp_step, scale, offset, unit, allowed, read_only, description. With replace an existing alias of that name is changed. Returns the stored definition.

    remove_alias¶

    remove_alias(name: 'str') -> 'None'

    Role: admin

    Remove an alias (refused while a composite channel uses it).

    define_composite¶

    define_composite(replace: 'bool' = False, **comp) -> 'dict'

    Role: admin

    Define a composite channel (type multi / read / map, see backend/composites.py). Returns its definition, the channels it provides and warnings (e.g. a variable that drives nothing).

    check_composite¶

    check_composite(replace: 'bool' = True, **comp) -> 'dict'

    Role: admin

    Check a composite definition without defining it (the editors' Check button): the mapping inverse check, references, dependency loops.

    remove_composite¶

    remove_composite(name: 'str') -> 'None'

    Role: admin

    Remove a composite channel (refused while another composite uses one of its channels).

    Parameters¶

    define_parameter¶

    define_parameter(name: 'str', value=None, formula: 'str' = '', unit: 'str' = '', description: 'str' = '', replace: 'bool' = False, definition: 'Optional[str]' = None) -> 'dict'

    Role: admin

    Define a parameter: a named constant of the setup, with a value or a formula of other parameters (no live channels, no circles). Or give definition, the text the user typed: a number becomes the value, anything else the formula. Parameters read like channels and may be used in composite formulas and actions. Returns its definition with the present value (current) and warnings.

    check_parameter¶

    check_parameter(name: 'str', value=None, formula: 'str' = '', unit: 'str' = '', description: 'str' = '', replace: 'bool' = False, definition: 'Optional[str]' = None) -> 'dict'

    Role: admin

    Check a parameter definition without defining it (the editors' Check button): {name, value | formula, current, warnings}; raises the error define_parameter would.

    remove_parameter¶

    remove_parameter(name: 'str') -> 'None'

    Role: admin

    Remove a parameter (refused while a parameter formula or a composite uses it).

    list_parameters¶

    list_parameters() -> 'list'

    Role: viewer

    Every parameter: {name, value | formula, unit, description, current, used_by}.

    User actions¶

    define_user_action¶

    define_user_action(name: 'str', code: 'str', description: 'str' = '', confirm: 'bool' = False, replace: 'bool' = False, rename_from: 'Optional[str]' = None) -> 'dict'

    Role: admin ⚡

    Define (or with replace change; with rename_from rename) a user action: a named Python snippet using the script API (see backend/user_actions.py).

    check_user_action¶

    check_user_action(name: 'str', code: 'str', description: 'str' = '', confirm: 'bool' = False, replace: 'bool' = False) -> 'dict'

    Role: admin

    Check a user action without defining it: its name and code, like check_code (ok is False for a bad name too).

    remove_user_action¶

    remove_user_action(name: 'str') -> 'None'

    Role: admin ⚡

    Delete a user action (refused while it runs).

    move_user_action¶

    move_user_action(name: 'str', position: 'int') -> 'None'

    Role: admin ⚡

    Move a user action to position (0 = first) in the list.

    abort_user_action¶

    abort_user_action(name: 'Optional[str]' = None) -> 'list'

    Role: operator ⚡

    Abort the running user action name (or every running one); returns the names asked to stop.

    list_user_actions¶

    list_user_actions() -> 'list'

    Role: viewer ⚡

    The user actions with their code, running flag and last run result.

    check_code¶

    check_code(code: 'str', what: 'str' = 'code') -> 'dict'

    Role: viewer

    Check Python code (a script, a user action, a point action) without running it: {ok, errors, warnings} - syntax errors, and quoted channels that do not exist (get('nope')).

    Monitor¶

    monitor_add¶

    monitor_add(channel: 'str', interval: 'float' = 1.0) -> 'list'

    Role: operator

    Poll channel every interval seconds and push its values to the front ends (monitor events). Returns the monitor list.

    monitor_remove¶

    monitor_remove(channel: 'str') -> 'list'

    Role: operator ⚡

    Stop monitoring channel; returns the monitor list.

    monitor_list¶

    monitor_list() -> 'list'

    Role: viewer ⚡

    The monitored channels with interval, last value, last error and time.

    monitor_history¶

    monitor_history(channel: 'Optional[str]' = None) -> 'dict'

    Role: viewer ⚡

    Recent values of one monitored channel (or of all): {channel: [[t, value], …]}.

    Sweeps and queue¶

    validate_sweep¶

    validate_sweep(definition: 'dict') -> 'dict'

    Role: viewer ⚡

    Check a sweep definition against the present channels without running it: all setpoints are computed and limit-checked. Returns {ok, warnings, shape, total_points, min_duration, definition} (the normalised definition) or raises with the first problem.

    queue_add¶

    queue_add(item: 'dict', start: 'bool' = False, position: 'Optional[int]' = None) -> 'int'

    Role: operator ⚡

    Add {kind: "sweep", definition} or {kind: "script", code, name} to the queue (at position, default the end); with start the queue starts. Returns the item id.

    continue_info¶

    continue_info(path: 'str') -> 'dict'

    Role: viewer

    Where an aborted run stopped and where continuing it would go on: {continuable, reason, status, error, run, name, points, total, ended, last_index, next_index, next_setpoints, aborts}.

    continue_sweep¶

    continue_sweep(path: 'str', wait: 'float' = 0.0, rerun_pre: 'bool' = True, start: 'bool' = False, position: 'Optional[int]' = None) -> 'int'

    Role: operator

    Queue the continuation of an aborted (or failed, or interrupted) run. It writes a new data file that starts with everything the old one recorded (the old file is not touched), goes on from the first point not measured - setting every sweep channel to it, then waiting wait seconds - and lists every abort in its header (aborts) and as events. rerun_pre: run the pre-sweep settings and hook again first (their recordings are kept as an event; the original pre-sweep values stay). Returns the queue item id.

    queue_remove¶

    queue_remove(item_id: 'int') -> 'None'

    Role: operator ⚡

    Remove a waiting queue item.

    queue_move¶

    queue_move(item_id: 'int', position: 'int') -> 'None'

    Role: operator ⚡

    Move a waiting queue item to position.

    queue_clear¶

    queue_clear() -> 'None'

    Role: operator ⚡

    Remove every waiting queue item.

    queue_start¶

    queue_start() -> 'bool'

    Role: operator ⚡

    Start processing the queue; False (and the queue stays idle) if it is empty.

    queue_stop¶

    queue_stop() -> 'None'

    Role: operator ⚡

    Stop after the current item (the rest stays queued).

    queue_state¶

    queue_state() -> 'dict'

    Role: viewer ⚡

    {state, can, processing, stop_on_error, current, queued, history}; state is idle / running / paused / aborting and can lists the controls that apply now.

    queue_options¶

    queue_options(stop_on_error: 'Optional[bool]' = None) -> 'dict'

    Role: operator ⚡

    Set queue options (stop_on_error: stop the queue when an item fails); returns the queue state.

    pause¶

    pause() -> 'None'

    Role: operator ⚡

    Pause the running item at the next point (sweeps) or line (scripts).

    resume¶

    resume() -> 'None'

    Role: operator ⚡

    Resume a paused item.

    abort¶

    abort() -> 'None'

    Role: operator ⚡

    Abort the running item; the sweep's post phase still runs (by default).

    abort_all¶

    abort_all() -> 'None'

    Role: operator ⚡

    Abort the running item, clear the queue and abort running user actions.

    run_script_now¶

    run_script_now(code: 'str', name: 'str' = 'script') -> 'int'

    Role: admin ⚡

    Queue a script at the front and start the queue.

    Runs and data¶

    current_run¶

    current_run() -> 'Optional[dict]'

    Role: viewer ⚡

    The running sweep: {run, name, path, status, progress, definition, paused}, or None.

    run_snapshot¶

    run_snapshot(last: 'bool' = True) -> 'Optional[dict]'

    Role: viewer

    Full dataset of the running sweep (or the last one when idle).

    list_runs¶

    list_runs(limit: 'int' = 200) -> 'list'

    Role: viewer ⚡

    The newest data files in the data folder (path, name, size, modification time).

    load_run¶

    load_run(path: 'str') -> 'dict'

    Role: viewer

    A stored run (complete or partial .emj file) as a snapshot: header, setpoints, data and status.

    read_run_header¶

    read_run_header(path: 'str') -> 'dict'

    Role: viewer ⚡

    Only the header of a stored run (its definition and metadata).

    make_ppt¶

    make_ppt(path: 'Optional[str]' = None, ppt_path: 'Optional[str]' = None) -> 'str'

    Role: operator

    Append a slide for a run file (or the current/last run) immediately.

    Setups¶

    save_setup¶

    save_setup(path: 'Optional[str]' = None) -> 'dict'

    Role: viewer ⚡

    The setup (instruments, aliases, composites, monitor list, user actions) as a dict; with path also written there as JSON.

    load_setup¶

    load_setup(setup: 'Optional[dict]' = None, path: 'Optional[str]' = None, replace: 'bool' = True, connect: 'bool' = True) -> 'list'

    Role: admin

    Load a setup from a dict or a JSON file. replace (default) removes what is there first; connect connects the instruments. Returns the problems found (an empty list when everything loaded).

    get_setup¶

    get_setup() -> 'dict'

    Role: viewer ⚡

    The present setup as a dict (see save_setup).

    remote_stop¶

    remote_stop(persist: 'bool' = True) -> 'dict'

    Role: local only ⚡

    remote_remove_user¶

    remote_remove_user(name: 'str') -> 'list'

    Role: local only ⚡

    Delete a remote account (local GUI only); returns the remaining accounts.

    remote_cert_request¶

    remote_cert_request(domain: 'str', email: 'str' = '', agree_tos: 'bool' = False, staging: 'bool' = False, http_port: 'int' = 80) -> 'dict'

    Role: local only

    Get a Let's Encrypt certificate for domain in a separate process (progress in remote_status()["cert"]["request"]); the gateway switches to it when done.

    remote_cert_use(mode: 'str', certfile: 'Optional[str]' = None, keyfile: 'Optional[str]' = None) -> 'dict'

    Use the self-signed certificate (mode="self-signed") or certificate files ("files", PEM chain + key); a running gateway switches within seconds.
