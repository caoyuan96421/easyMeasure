    sim_source – Simulated 4-channel DC voltage source (SCPI over SIM bus)¶

    simulated

    property value
    driver name sim_source
    module easymeasure.drivers.sim_source
    interfaces simulated bus (sim)
    suggested addresses SIM::GPIB0 (simulated GPIB bus (shared))
    shared port by default yes

    Base for simulated instruments that talk SCPI over a SIM:: port.

    Add it¶

    c.call("add_instrument", name="source", driver="sim_source", address="SIM::GPIB0")

    (SIM::GPIB0 is the driver's built-in emulator; use the instrument's real address for hardware.)

    Options¶

    option default
    gpib_addr 1
    error_rate 0
    garble_rate 0
    hang_rate 0
    hang_time 30
    disconnect_rate 0
    exception_rate 0
    nan_rate 0
    latency 0

    Plus the guard options every instrument has (call_timeout, retries, …, see Robustness).

    Channels¶

    Measurement / source channels, as the driver reports them connected to its emulator (SIM::GPIB0) in its default configuration. Mode and model settings can rename channels or change units; the front ends follow.

    channel access type unit allowed values description
    V1 rw float V output voltage 1
    V2 rw float V output voltage 2
    V3 rw float V output voltage 3
    V4 rw float V output voltage 4

    Configuration channels¶

    Settings: channels like the others (write_channel("inst.<name>", value), sweep pre/post constants), written as they are.

    channel access type unit allowed values description
    output rw str ON/OFF
    idn r str identification string

    Actions¶

    action description
    clear_status *CLS: clear the error queue

    Actions are write-only channels: writing one runs it, write_channel(name="<instrument>.<action>"), or set('<instrument>.<action>') in scripts.

    Python API¶

    Class SimVoltageSource in module easymeasure.drivers.sim_source.
