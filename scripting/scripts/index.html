    Queue scripts¶

    A queue script is a Python program that the backend runs from the run queue, just like a sweep. It waits its turn, it can be paused and aborted, and it appears in the queue history. Inside it you can set and read channels, wait for instruments and run sweeps, as many as you like, each into its own data file.

    This page uses the graphene setup from the tutorials (Setup → Load setup… → examples/graphene_setup.json).

    Your first script¶

    The task. You want to measure the Dirac peak carefully: 101 points in ±0.5 V around it, slowly. But you don't know exactly where it is, and it moves a little after every thermal cycle. By hand, you would run a quick coarse sweep, read off the peak, and then type the range into the editor. A script can do both steps in one go.

    Open the Queue tab. At the bottom is the Script editor.

    1. Open… loads a .py file into the editor (and Save… saves it). Open examples/scripts/find_dirac_then_zoom.py, or type it in.
    2. The script. It is shown in full below.
    3. A name for the queue and the log. Opening a file uses the file name.
    4. Add script to queue. Then Start the queue (at the top of the tab), as for a sweep. Run now puts it at the front of the queue and starts it at once.
    5. Check looks at the script without running it: a syntax error is shown with its line, and a channel name in quotes that does not exist (get('Vbgg')) is a warning. Add script to queue and Run now check first, and refuse a script that does not compile.

    The script:

    # An adaptive measurement: a quick coarse sweep finds the Dirac point, then a slow
# fine sweep measures ±0.5 V around it.  run_sweep() returns the run's data, so
# the script can decide what to measure next.
coarse = run_sweep({
    "name": "dirac_coarse",
    "dimensions": [{"points": 81, "sweep": [{"channel": "Vbg", "start": -8, "stop": 8}],
                    "record": ["Rxx"]}],
})
vbg = coarse.setpoints[0]["Vbg"]
r = coarse.data["Rxx"]
v0 = float(vbg[np.nanargmax(r)])
log("coarse sweep: Dirac point near Vbg = %.2f V (Rxx = %.0f Ω)" % (v0, np.nanmax(r)))
state["dirac_point"] = v0                  # remembered for later scripts and actions

fine = run_sweep({
    "name": "dirac_fine",
    "dimensions": [{"points": 101,
                    "sweep": [{"channel": "Vbg", "start": v0 - 0.5, "stop": v0 + 0.5}],
                    "record": ["Rxx"], "pre_delay": 0.05}],
    "post": {"constants": [{"channel": "Vbg", "value": 0}]},
    "metadata": {"found_from": coarse.path},
})
log("fine sweep %s: peak Rxx = %.0f Ω" % (fine.status, np.nanmax(fine.data["Rxx"])))

    Line by line:

    • run_sweep({...}) runs a sweep and waits until it has finished. The dictionary is the same as a sweep made in the editor (see A sweep is a dictionary): 81 points of Vbg from −8 to 8 V, recording Rxx. Like every sweep, it is checked against the limits of Vbg before it starts, and it is saved in its own data file.
    • run_sweep returns the measured data: coarse.setpoints[0]["Vbg"] holds the 81 gate voltages, and coarse.data["Rxx"] the 81 resistances, as numpy arrays.
    • np.nanargmax(r) finds the index of the largest resistance (nan points, if any, are skipped). v0 is the gate voltage of the peak.
    • log(...) writes a line to the log (the Log dock at the bottom of the window).
    • state["dirac_point"] = v0 keeps the result. state is a dictionary that stays in the backend until it is closed, so a later script or a user action can use state["dirac_point"].
    • The second run_sweep measures 101 points around v0, more slowly (pre_delay 0.05 s), sets Vbg back to 0 afterwards, and stores the file name of the coarse sweep in its metadata.

    After it has run:

    1. The queue history shows the script. Its sweeps appear in Live data while they run, like any sweep: here the fine sweep around the peak.
    2. The log, with the lines from log(...) and the files of both sweeps. File → Browse recent runs… (or Open data file…) opens them again.

    Pause and abort work everywhere

    Pause and Abort in the Queue tab act on a script as on a sweep: in a running run_sweep() at the next point, and otherwise at the next line of the script. Even an endless while True: loop can be aborted. Use sleep(...) to wait, never time.sleep(...), so the wait can be aborted at once.

    What a script can use¶

    Everything here is available without import:

    name does
    get('Rxx') read any channel: an alias, a composite channel, a parameter, instrument.channel
    set('Vbg', 1.0) write any channel. An alias keeps its limits and ramp rate (waits until the ramp is done); set('bg.voltage', 0) writes the instrument's channel as it is
    set_many({'nD.n': 0, 'nD.D': 0.2}) set several at once; needed for the variables of one composite
    set('vna.preset'), set('gates_to_zero') run an action (of an instrument, or a user action)
    sleep(2) wait 2 s (abortable)
    wait_until(lambda: get('magnet.status') == 'HOLDING', timeout=600) check every 0.2 s until it is true, for at most timeout s. Returns False on timeout
    run_sweep(definition) run a sweep, wait for it, return its data (below)
    load_sweep(path) a sweep saved with Sweep → Save…, or the sweep of a data file, as a dictionary
    instrument('vna').raw_query('*IDN?') talk to an instrument directly
    log('text'), print(...) write to the log
    state a dictionary kept between scripts and user actions
    np, math, time numpy and the standard modules

    The Script API reference has the full list. Any other module can be imported as usual (import json, from scipy.optimize import curve_fit).

    What run_sweep returns¶

    run_sweep() returns a DataSet, the same object as DataSet.load(path) gives for a data file:

    attribute is
    ds.status "finished", "terminated" (stopped by end_sweep()), "aborted" or "error"
    ds.data["Rxx"] the recorded values, a numpy array with one axis per dimension. Points not measured are nan
    ds.setpoints[0]["Vbg"] the set values of dimension 1 (setpoints[1]: dimension 2, …)
    ds.value_axes["S11"] the axes of a spectrum channel, e.g. the frequencies of a VNA trace
    ds.path the data file
    ds.header["definition"] the sweep that was run (its "metadata" key holds the metadata)

    An aborted sweep does not raise an error: check ds.status if the script should stop then too.

    Start from a saved sweep¶

    Rather than writing the dictionary by hand, design the sweep in the editor, check it with Sweep → Validate, and save it (Sweep → Save…). Then load it, change what should change, and run it:

    # Repeat a sweep designed in the sweep editor (and saved there with "Save…") at
# several top-gate voltages.  The Dirac peak moves and grows: the top gate adds
# carriers and a displacement field.
base = load_sweep("examples/graphene_dirac.json")    # a full path works too
for vtg in (-2, -1, 0, 1, 2):
    set("Vtg", vtg)
    sweep = dict(base, name="dirac_at_Vtg_%+g" % vtg, metadata={"Vtg": vtg})
    ds = run_sweep(sweep)
    v = ds.setpoints[0]["Vbg"]
    peak = int(np.nanargmax(ds.data["Rxx"]))
    log("Vtg = %+g V: peak %.0f Ω at Vbg = %.2f V" % (vtg, ds.data["Rxx"][peak], v[peak]))
set("Vtg", 0)

    dict(base, name=..., metadata=...) is a copy of base with two keys replaced, so each run gets its own name. Every run goes into its own file, with the top-gate voltage in its metadata.

    load_sweep also takes a data file, so "measure again what I measured yesterday" is run_sweep(load_sweep("D:/data/2026-11-10/00012_dirac_peak.emj")).

    Paths

    A relative path such as examples/graphene_dirac.json is relative to the folder the backend was started in. A full path is always safe.

    A series of sweeps¶

    A loop over conditions, with a wait for a slow instrument in between. This one runs a gate sweep at each of a list of fields. The fields need not be evenly spaced, and each gate sweep is its own file:

    # A sequence: one gate sweep at each of a list of fields, each in its own file
# with the field in its metadata.  The fields need not be evenly spaced.
fields = [0, 0.5, 1, 2, 4, 6, 9]
for b in fields:
    set("B", b)                                   # the magnet starts ramping
    wait_until(lambda: get("magnet.status") == "HOLDING", timeout=1200)
    sleep(1)                                      # let things settle
    ds = run_sweep({
        "name": "gate_at_%gT" % b,
        "dimensions": [{"points": 101, "snake": False,
                        "sweep": [{"channel": "Vbg", "start": -8, "stop": 8}],
                        "record": ["Rxx"]}],
        "metadata": {"B": b},
    })
    log("B = %g T: %s" % (b, ds.status))
    if ds.status != "finished":
        break                                     # aborted or failed: stop the series
set("B", 0)
set("Vbg", 0)
    • set("B", b) only sets the magnet's target. wait_until(...) waits until the supply reports HOLDING.
    • if ds.status != "finished": break ends the series when you abort one of the gate sweeps. Without it, aborting a sweep would just move on to the next field. To stop everything at once, use Abort all in the Queue tab.

    The same structure works for temperatures (set("Tset", T), then wait until get("T") is close), for sample positions, and so on.

    Compare this with tutorial 1, where the field is the outer dimension of a single 2-D sweep. A 2-D sweep is easier to plot as a map. A script is the better choice when the conditions are unevenly spaced, when something else has to happen in between (a gate sweep at some fields only, a warm-up, a recalibration) or when you want a separate file per condition.

    Safety checks first¶

    Combine a quick test with the real measurement: find how far the gate may go, then use only 90 % of that.

    # Safety first: find how far the back gate can go (stop at 1 nA of leakage), then
# measure the n–D map only within 90 % of that voltage.
test = run_sweep({
    "name": "leakage_test",
    "dimensions": [{"points": 201, "sweep": [{"channel": "Vbg", "start": 0, "stop": 10}],
                    "record": ["Ileak"],
                    "hooks": {"post_record": {"enabled": True,
                              "code": "if abs(values['Ileak']) > 1e-9: end_sweep()"}}}],
    "post": {"constants": [{"channel": "Vbg", "value": 0}]},
})
measured = np.isfinite(test.data["Ileak"])
v_max = float(test.setpoints[0]["Vbg"][measured][-1])
v_safe = 0.9 * v_max
log("leakage test %s: up to %.2f V, using %.2f V" % (test.status, v_max, v_safe))

# the largest |D| at n = 0 that keeps Vbg = (0.15 + D/0.0452) / 1.2 within v_safe
d_max = min(0.35, (1.2 * v_safe - 0.15) * 0.0452)
ds = run_sweep({
    "name": "n_D_map_safe",
    "dimensions": [
        {"points": 61, "sweep": [{"channel": "nD.n", "start": -1, "stop": 1}],
         "record": ["Rxx"], "snake": True},
        {"points": 15, "sweep": [{"channel": "nD.D", "start": -d_max, "stop": d_max}]}],
    "metadata": {"v_safe": v_safe},
})
log("map %s with |D| ≤ %.3f V/nm" % (ds.status, d_max))
set_many({"Vbg": 0, "Vtg": 0})

    The first sweep is the leakage sweep of tutorial 3, with its point action written into the dictionary as "hooks". Its last measured point is the last finite (not nan) value. The map then sweeps the composite channels nD.n and nD.D of tutorial 2, with the D range computed from the safe gate voltage.

    Scripts and the rest of easyMeasure¶

    • Queue a script after a sweep to have it run when the sweep is done, e.g. a script that ramps the field down at the end of the night.
    • Rerun a script from the queue history, or Copy to script editor to change it.
    • A script cannot be started from a user action or a point action, because they run outside the queue. Queue it instead.
    • Over remote access, scripts need the admin role: a script is Python with full access to the measurement computer.
