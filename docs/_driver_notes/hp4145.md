HP 4145A/B semiconductor parameter analyzer, and the HP 4155/4156 in 4145 syntax.

The analyzer is put into HP-IB **user mode** (`US`). Every SMU is forced (`DV` / `DI`)
and measured (`TV` / `TI`) point by point, so it works like four source-measure units,
with the same `mode<n>` logic and adaptive compliance as the
[Keithley 2400](keithley2400.md).

* Per SMU 1…4: `voltage<n>`, `current<n>`, `mode<n>`, `Icompliance<n>` /
  `Vcompliance<n>`, `output<n>` and `range<n>`.
* Voltage sources `vs1`, `vs2` and voltage monitors `vm1`, `vm2`.
* `integration`: short / medium / long.

**Settings.** User mode has no setting queries, so settings are remembered by the
driver. A value written while `output<n>` is OFF is applied when it is switched ON;
this needs a compliance first.

**Output envelope.** The envelope is checked before anything is sent:

| current | voltage |
|---|---|
| 100 mA | ≤ 20 V |
| 50 mA | ≤ 40 V |
| 20 mA | ≤ 100 V |

**Reconnect.** A reconnect does not touch the outputs; they then read OFF until set
again.

**4155 / 4156.** A 4155/4156 is switched into its 4145 syntax command mode
automatically when it is in SCPI mode (`:SYST:LANG COMP`) or FLEX mode (`:PAGE`
first), checked with `CMD?`. The option `force_4145_syntax` = false leaves the mode
alone.

Not yet confirmed from the manual text:

* the mode switch commands;
* the VS/VM channel numbers (5, 6) and `DS <ch>`;
* the exact TV/TI reply layout. The parser accepts the usual variants: status
  character first and number last; overflow reads as ±inf, oscillation as NaN.
