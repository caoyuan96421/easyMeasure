NI USB-6211 multifunction DAQ, through NI-DAQmx. It needs NI's NI-DAQmx driver
runtime; the `nidaqmx` Python package comes with easyMeasure.

**Address**: `DAQ::Dev1`, the device name in NI MAX. `DAQ::SIM` is the built-in
emulator, with loop-back wiring: `aiK` sees `aoK`.

**Channels**: `ai0…ai15` (`ai0…7` in DIFF), the vector `ai`, `ao0`, `ao1`,
`di0…3`, `do0…3`, `ctr0` and `ctr1`.

**Settings**: `rate`, `samples`, `terminal` (RSE / NRSE / DIFF) and `ai_range`.

**Readings.** Every analog reading is the mean of `samples` samples at `rate` per
input. It acquires only the inputs it returns:

* `ai3` alone, up to 250 kS/s;
* the vector `ai`, all inputs of one scan, which share the 250 kS/s. The option
  `ai_channels`, e.g. `"0-3"`, puts fewer inputs in it. A vector reading too fast for
  its inputs is refused; the single inputs still work.

`samples = 1` is a single on-demand conversion, taking well under a millisecond.
